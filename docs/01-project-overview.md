# 01 — Project Overview

## What is this app?

**NuxtTodo** is a simple todo list app built to demonstrate Vue 3, Nuxt 3, and Nuxt UI.
It stores your todos in your browser's `localStorage` — no server or database required.

### Features

- ✅ Add, edit, and delete todos
- 🏷️ Open-ended tags (type any tag you like)
- 📅 Optional due dates
- 🔍 Search and filter by tag or status
- 📆 Calendar view — see which days have todos due
- 🌙 Dark mode (click the sun/moon button in the header)
- 💾 Auto-saved to `localStorage` (data persists across browser refreshes)

## Data flow

```
localStorage
     │
     ▼
useTodos.js (composable)
     │  todos (useState — shared reactive state)
     │
     ├── pages/index.vue       reads: todos, allTags, activeCount
     │        │                calls: addTodo, updateTodo, deleteTodo, toggleComplete
     │        │
     │        ├── AppTodoItem.vue     displays one todo row
     │        └── AppTodoModal.vue    form for adding/editing
     │
     └── pages/calendar.vue    reads: todos, getTodosForDate
              │                calls: addTodo, toggleComplete, deleteTodo
              │
              └── AppCalendar.vue     renders the month grid
```

The key insight: **both pages share the same `todos` array** via `useState()` in the composable.
A change on one page instantly appears on the other.

## The todo data model

Each todo is a plain JavaScript object with these fields:

```js
{
  id:          "1a2b3c",          // unique string identifier
  title:       "Buy groceries",   // required short label
  description: "Milk, eggs…",     // optional longer notes (can be empty string)
  tags:        ["shopping","home"],// array of lowercase tag strings (can be empty)
  dueDate:     "2025-06-15",      // optional YYYY-MM-DD date string, or null
  completed:   false,             // boolean — true when done
  createdAt:   "2025-06-01T…"     // ISO timestamp string
}
```

All todos live in a single reactive array.  Every CRUD operation (add, update, delete, toggle)
mutates that array, and a `watch()` in the composable immediately writes it to `localStorage`.

## How the app renders

1. Browser loads `index.html` (generated by Nuxt)
2. Nuxt boots the Vue app, mounts `app.vue`
3. `app.vue` renders `<UHeader>`, `<UMain>`, and `<NuxtPage />`
4. `<NuxtPage />` renders the current route's page (e.g. `pages/index.vue`)
5. The page calls `useTodos()` to get state, renders a list of `<AppTodoItem>` components
6. When the user clicks "Add Todo", `isModalOpen` becomes `true` → `<AppTodoModal>` appears
7. On save, `addTodo()` pushes to `todos` → Vue re-renders the list → `watch()` saves to localStorage
