# Nuxt Todo + Calendar Learning Demo

A beginner-friendly demo app that shows **Vue**, **Nuxt**, and **Nuxt UI** in one project.

You can:
- Add todos
- Add open-ended tags (`work`, `home`, `learning`, etc.)
- Switch between **list view** and **calendar view**
- Filter todos by status/tag
- Keep todos after refresh (localStorage)

---

## Why this repo exists

This project is designed for learning by example, especially if you already know plain HTML/CSS/JS and want to understand how frameworks improve structure, reusability, and state management.

---

## Quick start

```bash
npm install
npm run dev
```
